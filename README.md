# Logistic Regression From Scratch

A NumPy implementation of logistic regression from first principles, including gradient descent and binary classification (extending to multiclass classification in the future).

## Overview

This project implements logistic regression without machine learning libraries. The goal is to understand how logistic regression works under the hood while following software engineering practices.

## Features

- Gradient descent optimization
- Binary classification
- Cross-entropy loss
- Probability predictions
- Model evaluation
- Unit tests
